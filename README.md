# VECTOR — архитектура продаж под ключ

Лендинг проекта Георгия: создание и сопровождение систем продаж от первого обращения до договора.

## Публикация

Статический сайт: `index.html`. Не требует сборки, сервера или платных сервисов.

После включения GitHub Pages из ветки `main` и папки `/ (root)` сайт будет доступен по адресу:

https://serega40in.github.io/vector-sales/
